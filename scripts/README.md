# Data acquisition

This directory contains instructions and adapters for bringing authorized public parcel exports into the pipeline.

The current St. Joseph County workflow should use the county's public GIS/Parcel Layer and its Simple Query tools. The county's public GIS guide documents searching by address or parcel and querying layer attributes.

Do not scrape private records, bypass access controls, or infer sensitive personal information. Store source URL, retrieval date, and evidence fields with every imported record.
