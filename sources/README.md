# Research sources

The agent is designed around public, attributable sources. The first source profile is St. Joseph County, Indiana.

## Initial official sources

- County GIS / parcel data: https://www.sjcindiana.gov/1443/Data-Extract-Search-Information
- Assessment neighborhood / property record cards: https://www.sjcindiana.gov/1649/Assessment-Neighborhood-Map
- Land records: https://www.sjcindiana.gov/412/Land-Records-Search
- Auditor / ownership and parcel information: https://www.sjcindiana.gov/auditor

The county states that property information is available in its Parcel Layer and provides a Simple Query Builder for data analysis. The assessment map supports parcel and property-record-card lookup. Land records are available through the Recorder's search tools.

The agent should store the exact source URL and retrieval timestamp with each evidence item. It must not label a record verified merely because one source returned a value.
